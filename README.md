# 💰 Expense Tracker

A mobile application for tracking personal expenses, built from scratch directly on Android.

This project is part of a YouTube series demonstrating how to develop a mobile application using only an Android device, without a computer or a backend.

---

## About

**Expense Tracker** is a personal finance application designed to help users record, organize, and monitor their expenses.

The application is being developed step by step, from the initial project setup to the implementation of its core features.

---

## Tech Stack

- **[React Native](https://reactnative.dev/)** — Mobile application development
- **[Expo](https://expo.dev/)** — Development and application tooling
- **[TypeScript](https://www.typescriptlang.org/)** — Type-safe JavaScript
- **[Yarn](https://yarnpkg.com/)** — Package management
- **[Neovim](https://neovim.io/)** — Code editor
- **[Termux](https://termux.dev/)** — Android terminal environment
- **[Node.js](https://nodejs.org/)** — JavaScript runtime

---

## Development

The entire development process takes place directly on an Android device using Termux and Neovim.

The project is built incrementally, with each stage introducing new functionality as the application evolves.

## Getting Started

### Prerequisites

- An Android device
- [Termux](https://termux.dev/)
- [Node.js](https://nodejs.org/)
- [Yarn](https://yarnpkg.com/)
- [Neovim](https://neovim.io/)
- [Expo Go](https://expo.dev/go)

### Installation

Clone the repository:

```bash
git clone https://github.com/Justino-code/expense-tracker.git
cd expense-tracker
```

Install the dependencies:

```bash
yarn install
```

Start the development server:

```bash
yarn start
```

Follow the Expo instructions to open the application in Expo Go.
